# Claude — all skills and source files

All 485 distinct skills are visible here: 472 with a ZIP and 13 with source files and repair warnings. The 86 command entries are visible separately under Claude Code Commands. Together these represent all 925 catalog entries, including identical source copies.

1. Open a topic. Coding, design, writing, marketing, research, and tools/workflows topics have smaller task-based subcategories; then open the clearly named skill folder. SKILL.md and supporting files are directly inside, beside the upload ZIP.
Read VAULT GUIDE.md for setup warnings. Same-name distinct variants have a suffix to prevent overwriting.
2. Read its requirements, then select its ZIP. Do not unzip that individual ZIP.
3. In Claude, use Customize → Skills → add/create → upload (labels may vary).
4. Try a harmless task and confirm the skill activates.

No manual zipping or Terminal commands are needed. Available ZIPs passed structural checks, not live Claude imports or a full code/security review. Enable only what you need. Do not install same-name variants together without review.

Skills requiring tools or host setup remain here, with warnings inside their own folders. All source versions are preserved under 🔧 ADVANCED.

Official guide: https://support.claude.com/en/articles/12512198-how-to-create-custom-skills
