with the owner's approval. This checklist now concerns a future public release.

- [x] Confirm private repository name and visibility.
- [ ] Review provenance and redistribution rights for every package and asset,
      including inherited licenses, fonts, document templates and binaries.
- [ ] Preserve notices and satisfy license obligations.
- [ ] Choose a license for original tooling only, not the entire aggregation.
- [ ] Resolve or explicitly withhold standalone packages with missing resources;
      keep all excluded originals privately.
- [ ] Pass tests, generated-metadata checks and exhaustive export verification.
- [ ] Review final Git tree AND history for credentials and personal data,
      including archives and embedded document properties.
- [ ] Test representative imports in the actual Claude and ChatGPT accounts.
- [ ] If needed, prepare a fresh publication tree without withheld archive history.
- [ ] Obtain explicit public-release authorization before changing visibility.
- [ ] Verify a fresh remote clone and release downloads.

Do not publish this entire archive until rights/provenance are resolved.
A private preparation copy is not redistribution clearance.
