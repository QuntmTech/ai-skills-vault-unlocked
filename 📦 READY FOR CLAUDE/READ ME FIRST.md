# Ready-made Claude ZIPs

1. Open a topic folder here and choose a skill ZIP. The website is optional.
2. Read its requirements, then select its ZIP. Do not unzip that individual ZIP.
3. In Claude, use Customize → Skills → add/create → upload (labels may vary).
4. Try a harmless task and confirm the skill activates.

No manual zipping or Terminal commands are needed. These packages passed structural checks, not live Claude imports or a full code/security review. Enable only what you need. Do not install same-name variants together without review.

Skills requiring known tools or host setup are in ⚠️ NEEDS SETUP. All source versions are preserved under 🔧 ADVANCED.

Official guide: https://support.claude.com/en/articles/12512198-how-to-create-custom-skills
