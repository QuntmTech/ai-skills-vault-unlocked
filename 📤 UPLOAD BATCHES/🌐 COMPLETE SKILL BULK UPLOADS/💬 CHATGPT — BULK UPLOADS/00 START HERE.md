# ChatGPT bulk uploads

**01 ALL PRIMARY SKILLS** contains 428 distinct internal skill names. ChatGPT skill upload is available only on eligible plans/workspaces with the required permissions.

Each numbered batch contains at most 20 individual ZIP files. Open one Batch folder, select all ZIPs in that folder, and upload them together only if your interface supports multi-selection. Do not upload the Batch folder itself. Packages passed structural checks, but no live account imports or runtime behavior are claimed. Skills that require external tools, credentials, local paths, or code execution still need that setup after installation.

The alternate section is preserved for completeness but is not a bulk-upload queue: those packages share internal names with primary choices and can trigger Replace/Already exists prompts.
