# Curation and privacy notes

This is a new, generalized synthesis of selected instruction-library material,
not a dump of the original folders or a claim that every archived version was
read end-to-end.

## Themes reviewed and retained

| Instruction family | Reusable ideas |
| --- | --- |
| Instruction architecture | Short core, deeper references, explicit task and failure handling |
| Coding and tool contracts | Inspect first, preserve working systems, scoped authority, real verification |
| System operations and file organization | Root-cause diagnosis, recoverability, content-based classification |
| Research frameworks | Source authority, uncertainty, corroboration and decision relevance |
| Design guidance | Intentional composition, usable outputs and context-sensitive constraints |
| Writing and claims review | Edit-scope fidelity, evidence-backed persuasion and factual preservation |
| Business strategy | Bounded validation, economics, focus and measurable outcomes |
| Specialist decision systems | Context-specific evidence and restraint around consequential actions |

## Deliberately not included

- Personal names, identities, locations, businesses, account details and profiles.
- Personal revenue goals, spending patterns, preferences or historical incidents.
- Private project dossiers, live infrastructure, local paths, private links and logs.
- Credentials, customer data and original source archives.
- Stale prices, model names, platform dimensions, legal deadlines or numeric targets.
- Instructions to override the host, treat all attachments as authoritative,
  invent tool access, bypass consent or assume permanent memory.
- Unsupported success guarantees, fixed scoring shortcuts and unnecessary
  requirements to browse, use every tool or read every file for every task.

The result is topic-general and provider-neutral. It does not reproduce the
source library's private voice, business identity or product-specific state.

## Review boundaries

Automated privacy checks flag common identifiers and secret-like patterns.
Manual review is still needed for contextual identifiers that a regex cannot
recognize. The check applies to this new compilation, not a blanket privacy
certification of every older skill in the repository.

No original source file was edited or copied into this bundle. Existing
repository-wide publication and licensing gates still apply; no new blanket
license or public release is implied.
