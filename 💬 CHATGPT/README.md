## Set up a ChatGPT project

1. Open or create a ChatGPT project.
2. Open **Project Instructions/PROJECT-INSTRUCTIONS.md**. Copy the relevant guidance into the project's supported instruction area, within its limits.
3. Add **PROJECT-HANDBOOK.md** as a project source if you want the longer reference. Alternatively use **COPY-PASTE-ALL.md** instead of loading both separate documents.
4. Pick only the skill references relevant to your current task and add them as sources, or paste a relevant excerpt into a chat. Do not upload all references at once.
5. Start a chat in the project and test with non-sensitive sample content. Tell ChatGPT which reference to use and what result you need.

ChatGPT projects can share instructions and uploaded sources across their chats. Account controls and file limits can vary. See [OpenAI's project documentation](https://learn.chatgpt.com/docs/projects).

## Use a reference for a single task

Open **Skill References**, choose a topic and—where available—a subcategory, then read one clearly named document. Each copy includes requirement warnings and a link back to its preserved source. The original instruction text is retained; it has not been rewritten or certified as ChatGPT-compatible.

You can adapt this starter message after supplying the chosen document:

> Use the attached reference to help with this task: [describe the task]. My desired result is [format and outcome]. Apply only the parts relevant to this environment. If it requires an unavailable tool, account, script, or supporting file, tell me what is missing instead of claiming you ran it. Do not change files or connect services without my approval.

Review the answer yourself. A document attachment does not install software, connect accounts, or grant new permissions.

## If you download the reference-pack ZIP

Extract **ChatGPT-Reference-Pack.zip** once, then choose the individual Markdown documents inside. This ZIP is a convenient document bundle, **not** a one-click skill installer. There is no need to re-ZIP the documents.

Supporting scripts and assets stay in the full vault's Advanced source folders. Source links require the full vault layout; they will not resolve when you extract this smaller document-only bundle elsewhere.

## Native skills are a separate route

OpenAI documents standalone skills for ChatGPT desktop and Codex, plus plugin-distributed skills across supported ChatGPT surfaces. This section does not install those. A dedicated native distribution requires separate packaging, dependency review, and live testing. See [OpenAI's skills documentation](https://learn.chatgpt.com/docs/build-skills).

## Keep private material private

- Never put credentials, customer records, or private project details into this shared repository.
- Save any completed **PROJECT-CONTEXT.template.md** outside the vault.
- Treat scripts, service connections, and provider-specific commands in references as requirements to review, not instructions to execute automatically.
- Existing license and attribution restrictions still apply. These reference copies do not grant resale or redistribution rights.

All existing Claude packages and original source files remain in their existing locations.
